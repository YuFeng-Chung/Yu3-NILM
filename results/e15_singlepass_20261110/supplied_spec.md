# E15：單次推論＋變動第二通道（1P-NoiseCh、1P-Mix）實驗規格

來源：作者在本對話於2026-11-09提供（Claude建立；Justin已同意補做，論文定位採甲案）。原指定路徑在準備時不存在，因此此處保存提供內容；不寫入其他研究目錄。規則在結果產生前凍結。

## 1. 目的
E14 顯示：訓練時第二通道只要非零且會變化（NoiseFB、PermFB），第一次推論對未見脈衝的穩健性即與 Yu3 相當；全零（ZeroFB）則無效。本實驗回答：是否根本不需要兩次推論，只要單次推論、在第二通道加入雜訊即可？

## 2. 新增兩個受訓模型
隔離副本，沿用 E14 的 e14_core.py 結構，不改任何原有模式。與 Yu3／NoiseFB 相同的兩通道編碼器、解碼器與分類器；只做一次前向運算；損失 L = CE + 0.5·MSE(X̂, X)。
- 1P-NoiseCh（主要）：訓練輸入一律為 [X, N]。
- 1P-Mix（次要）：每個訓練樣本以機率 0.5 取 [X, 0]、0.5 取 [X, N]，依穩定亂數決定。

N = clamp(μ0 + σ0·ε, min=0)，ε ~ N(0,1) 逐像素獨立。μ0、σ0 為固定純量：以 E14 NoiseFB 十個 final checkpoint，在 855 筆訓練影像上計算第一次推論絕對殘差 R 的逐樣本像素平均與標準差，再取全部樣本×種子的中位數。開跑前寫入 noise_scale.json，之後不得更改；不得使用任何測試資料。
亂數與 E14 相同：SHA256 穩定種子（訓練 seed,epoch,batch 序號；推論樣本 ID），CPU torch.Generator，不消耗全域亂數。

## 3. 訓練協定
只做 No-Defense；lr 5e-4、weight decay 0、dropout 0.5、batch 32。各模型以內層驗證 pilot 決定 epoch（min30、patience30、max150），不得看外層測試。種子42–51；原855／219切分；訓練集固定V/I正規化；同一Mac／MPS；推論batch32。輸出只在本目錄，既有研究來源與結果不得修改。

## 4. 評估
與E4／E14相同的全部擾動條件與污染實現（seed1000–1009）。每模型報告 [X,0]（主要；對應Yu3第一次推論部署）與 [X,N]（次要；推論雜訊依樣本ID固定）。

## 5. 事先訂定的主要比較與判讀
主要端點：No-Defense、脈衝5%、10%、20%，[X,0] Macro-F1。
主要比較：1P-NoiseCh 對 NoiseFB 第一次推論、1P-NoiseCh 對 ZeroFB；每個強度內兩項精確雙尾配對Wilcoxon（n10），Holm校正。1P-Mix同法、作次要分析。NoiseFB／ZeroFB使用E14保存數值，不重訓。
逐強度套用（3pp為描述性門檻，非等效檢定）：
- 顯著高於ZeroFB，且與NoiseFB平均差在3pp以內 → 不需要兩次推論；穩健性來自訓練時的變動輔助通道。
- 與ZeroFB平均差在3pp以內，且顯著低於NoiseFB → 兩次推論是必要的。
- 介於兩者之間 → 照實報告為部分效果。各強度不一致時逐強度報告，不挑選有利強度。
探索性（不校正）：Yu3第一次推論、RecAux、M1；AWGN各強度。不論結果如何，皆寫入主文III-C、補充資料與回應信。
